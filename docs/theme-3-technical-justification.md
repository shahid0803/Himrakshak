# Theme 3 technical justification

HimRakshak belongs to DeepTech and Autonomous Systems through its concrete
embedded engineering: ESP32 ADC acquisition, local filtering, sensor-health
diagnostics, deterministic multi-sensor rules, a local state machine,
actuator control, verified TLS, bounded queues, retry/backoff, and distributed
virtual node profiles.

It does **not** claim quantum computing, semiconductor fabrication, machine
learning, physical deployment, real sensors, LoRa radio behavior, or calibrated
landslide prediction. Wokwi is a virtual hardware prototype and the Python
backend is a standard-library integration and reliability demonstrator.

For judges, the key distinction is autonomy: the ESP32 can classify a
demonstration condition and drive local responses while disconnected; the
dashboard is an observability and telemetry layer, not a prerequisite for
local control.
