# HimRakshak TinyML 240,000-row update

This update expands the synthetic demonstration dataset to **240,000 rows**
(80,000 per class), retrains the compact Decision Tree, and re-exports the
embedded C++ header.

## Files included

- `data/processed/himrakshak_synthetic_v2.csv` — 240,000 generated rows
- `data/processed/himrakshak_synthetic_v2.manifest.json` — row counts, seed and SHA-256
- `scripts/generate_tinyml_dataset.py` — 240k default and rule-based balanced sampling
- `train_tinyml.py` — 240k training default and metadata export
- `models/himrakshak_tinyml_v2.json` and `models/training_metrics_v2.json`
- `wokwi_esp32_demo/HimRakshakModel.h` — newly generated tree header
- `wokwi_remote_patch/HimRakshakModel.h` — same header for the active Wokwi project
- Updated tests and training/evaluation documentation

## Apply to an existing cloned repository (Windows PowerShell)

Extract this ZIP into a temporary folder, then copy its contents over the
existing clone. Example:

```powershell
$repo = "$env:USERPROFILE\Downloads\HimRakshak-live"
$patch = "$env:USERPROFILE\Downloads\HimRakshak_240k_TinyML_Update"

Expand-Archive `
  "$env:USERPROFILE\Downloads\HimRakshak_240k_TinyML_Update.zip" `
  -DestinationPath $patch -Force

robocopy $patch $repo /E
cd $repo

python -B -m unittest discover -s tests -v
python -m compileall -q himrakshak tests scripts

git add -A
git commit -m "Expand TinyML synthetic dataset to 240k"
git push origin main
```

The CSV is about 32.5 MB uncompressed, below GitHub's 100 MB per-file limit.

## Update the Wokwi model

Open the existing HR-01 Wokwi project and replace **only** its
`HimRakshakModel.h` with `wokwi_remote_patch/HimRakshakModel.h` from the updated
repository. This header is a generated artifact and its SHA-256 must match the
JSON model. Keep the 16-feature order and the remote-control firmware files
unchanged. Save and restart Wokwi after replacing the header.

## Training result

- 240,000 rows: 80,000 per class
- 180,000 train / 60,000 stratified holdout
- Decision Tree: depth 5, 53 nodes
- Synthetic holdout accuracy: 97.14%
- Synthetic CRITICAL recall: 99.975%
- The representative HR-01 Wokwi NORMAL / HEAVY_RAIN / SLOPE_MOVEMENT vectors
  classify as 0 / 1 / 2 in both the retrained Python model and generated C++.
- Full Python suite: 158 tests passed; C++11 header smoke test passed.

## Scientific limitation

All 240,000 rows are synthetic, generated by the project's own class-conditioned
Monte Carlo script. Labels are assigned by explicit prototype thresholds using
balanced rejection sampling. They are not actual field records or 240,000
independent landslide events. Holdout metrics measure agreement with those
synthetic rules only and must not be described as real-world landslide
prediction accuracy or field validation.
